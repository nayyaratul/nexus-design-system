Toggle control for binary or indeterminate selections. Built on Radix UI's Checkbox primitive for robust keyboard and screen reader support.

## Accessibility

- Built on `@radix-ui/react-checkbox`, which manages `aria-checked` (including the `mixed` state for indeterminate).
- Always pair with a visible `<label>` linked by `id`/`htmlFor`, or provide an `aria-label`.
- Supports `disabled` and `required` attributes natively.
- Full keyboard support: `Space` toggles the checkbox.
