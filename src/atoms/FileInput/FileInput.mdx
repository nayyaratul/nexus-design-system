# FileInput

A styled file-upload control that replaces the browser's native file input. It shows an upload button and an optional filename label with truncation tooltip.

<Controls />

## Sizes

Three sizes: `sm`, `md`, and `lg`.

Wrap in a `FormField` for label, hint, and error messaging.

<Canvas of={FileInputStories.Default} />

## Accessibility

- The native `<input type="file">` is visually hidden but remains in the DOM for assistive technology.
- The visible button triggers the hidden input on click.
- `aria-invalid` is set when `error` is true.
- Truncated filenames display a tooltip on hover.
