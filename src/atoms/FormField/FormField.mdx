# FormField

A layout wrapper that pairs a label, hint text, and error message with any form control. Use it to build consistent, accessible form layouts.

## Accessibility

- Renders a `<label>` element linked to the control via `htmlFor`.
- Error messages use `role="alert"` for immediate screen-reader announcement.
- Required fields display a visual indicator on the label.
